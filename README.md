
# SPACE MINE 🚀

Space mining game for Telegram.

## Game Features
- Space mining
- Collect resources
- Energy system
- Drill upgrades
- Battery upgrades
- Unlock new planets

## Planned Features
- Telegram Mini App
- Telegram Bot
- Secure Database
- Daily Missions
- Leaderboard

## Project Goal
Build a sustainable long-term game.

## Security
Never expose bot tokens or API keys.
